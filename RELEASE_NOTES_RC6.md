# Sharda Library 3.0.0-rc.6

## Navigation and Settings update
- Renamed the existing Reports & Data Tools page to **Settings**.
- Added/updated the Admin Sidebar navigation entry to open Settings as its own page.
- Updated the Dashboard Quick Actions shortcut from View Reports to Settings.
- Kept existing reports, CSV export, JSON backup/restore, library configuration, admin password OTP workflow, server backups, and Activity Log inside Settings.
- Booking Requests remains a separate Admin Sidebar section.
- Membership Expiry remains a separate Admin Sidebar section with its four clickable, colorful categories: Overdue, Expires Today, Expires Tomorrow, and Next 5 Days.
- Preserved the RC.5 independent main-content and sidebar scrolling behavior and sticky top bar.
